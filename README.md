# Fully Groan — Dad Joke Showdown entry

One original dad joke for the make.fun Dad Joke Showdown: a father–son exchange at the table that ends on a grown/groan homophone. `main.ts` (program/v1) reads the joke from `entry.txt`, checks it against the 1–200 character gate, and writes it to `/output/entry.txt` with a read-back verification.
